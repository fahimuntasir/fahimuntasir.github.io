# MD FAHIM MUNTASIR – Personal Portfolio

This repository contains the source code for my personal portfolio website, built and hosted using **GitHub Pages**.

🔗 **Live Website:** https://fahimuntasir.github.io/

---

## 📌 About This Project

This portfolio is designed to present my academic background, professional experience, technical skills, and projects in a structured and accessible format.  
It serves as a digital profile for academic applications, professional opportunities, and professional networking.

---

## ✨ Portfolio Features

- Responsive layout for desktop, tablet, and mobile screens.
- Light and dark themes with a theme toggle.
- Featured technical projects with repository links and an expandable additional-projects section.
- Compact professional-experience timeline with expandable responsibilities and earlier roles.
- Expandable training and workshop details.
- Sections for education, research focus, technical skills, honours, languages, and contact information.

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- Font Awesome  
- Google Fonts
